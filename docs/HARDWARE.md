# 硬件与适配范围

已验证样机为 Huawei EC6108V9，Hi3798MV100 四核 ARMv7，1 GiB RAM，
eMMC 总容量 3,959,422,976 字节，板级启动配置 `mdmo1d`。
外壳型号相同不代表 PCB、DDR、闪存或无线芯片相同。

| 功能 | 状态与边界 |
| --- | --- |
| CPU / SMP | 四核、独立定时器及热插拔已有测试记录 |
| eMMC | ext4 直接根分区、读写和普通重启持久化已验证 |
| SD | 4-bit / 25 MHz；正常 64 GB 卡读写、同步、自动挂载及重启校验通过 |
| USB | 两个外部口有识别/存储测试记录；最终固化轮次未重复全部端口用例 |
| Ethernet | DHCP、双向传输已验证 |
| Wi-Fi | RTL8188ETV，rtl8xxxu 驱动；关机卸载后，两次普通重启自动连接和传输通过 |
| 随机数 | 修复合法短读处理，硬件 RNG 已有验证记录 |
| NAT / netfilter | 模块和网络命名空间功能已测试，参见系统审计 |
| HDMI / 音频 / GPU / 视频解码 | 当前配置禁用，未验证 |
| 温度 / 动态调频 | 尚未提供可用接口 |
| 长期稳定性 | RC 社区内核，尚未完成长期老化；不宣称生产级稳定 |

SD 使用不同卡做过对照：旧卡在旧内核和新内核下均无法初始化，另一张卡在相同插槽正常。
这与 MMC 大块读超时的驱动修复是两件事，详见 `docs/validation/`。
最终固化时 SD 已移除，不能把之前的 SD 测试记作该轮重新测试。

## 引导与分区

本机沿用已有 U-Boot 和板级参数，Linux 通过 `blkdevparts` 定义分区，无常规 MBR/GPT 表。

| 区域 | 起始位置 | 大小 | 用途 |
| --- | --- | --- | --- |
| p1 | 0 | 14 MiB | 必需的引导、环境变量及板级参数 |
| p2 | 14 MiB | 20 MiB | 唯一内核，U-Boot 实际读取前 8 MiB |
| p3 | 34 MiB | 至 eMMC 末尾 | 唯一 ext4 根系统 |

环境变量位于 eMMC 1 MiB 处，前 64 KiB 使用 CRC，安装器保留其余板级数据。
eMMC `boot0/boot1` 是硬件区域，不是另一个系统。设备上没有 HiNAS 或旧系统回退入口。
启动参数、CRC 处理和分区几何检查见 `tools/prepare-direct-install.py`。

当前 DTS 为保持已验证样机行为仍保留原板级固定 MAC。
多台设备部署前必须分配不同 MAC，并重新验证网络配置；不能直接批量克隆本机私有镜像。
